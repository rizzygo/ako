# Como contribuir

Obrigado por querer melhorar a Iniciativa Ako. Toda contribuição conta, da correção de uma vírgula a um guia novo.

## Jeitos de ajudar

- **Abrir uma issue:** para apontar um erro, sugerir uma pergunta nova ou pedir um guia sobre um tema.
- **Mandar um pull request:** para corrigir ou melhorar um conteúdo que já existe, ou para propor um novo.
- **Contar como usou:** abra uma issue dizendo como o guia funcionou para você. Isso ajuda a saber o que vale a pena aprofundar.

## Primeira vez no GitHub?

1. Abra o arquivo que você quer melhorar e clique no ícone de lápis para editar.
2. Faça a alteração e descreva em uma linha o que mudou.
3. Clique em "Propose changes" e depois em "Create pull request".

Pronto. A gente revisa e conversa nos comentários se precisar.

## Combinados

- **Escreva para quem está começando.** Frases curtas, sem jargão sem explicação.
- **Teste antes de propor.** Se é um comando ou uma instrução para IA, rode ou teste antes.
- **Diga de onde veio.** Se usou um estudo, artigo ou documentação, coloque o link.
- **Respeito sempre.** Pergunta básica é bem-vinda. Aqui ninguém é exposto por errar.

## Estrutura

```
guias/
  nome-do-guia/
    README.md       o guia em si
    instrucao.txt   o texto pronto para colar na IA, quando houver
```
