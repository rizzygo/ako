# Como contribuir com a Iniciativa Ako

Obrigado por querer melhorar os guias. Toda contribuição conta, da correção de uma vírgula a um guia novo.

## Três jeitos de ajudar: issue, pull request ou relato de uso

- **Abrir uma issue** (um tópico de conversa no GitHub) para apontar um erro, sugerir uma pergunta nova ou pedir um guia sobre um tema.
- **Mandar um pull request** (uma proposta de alteração) para corrigir um conteúdo que já existe ou propor um novo.
- **Contar como foi usar um guia** numa issue. Seu relato mostra o que vale a pena aprofundar.

## Primeira vez no GitHub? Dá para editar pelo navegador

1. Abra o arquivo que você quer melhorar e clique no ícone de lápis.
2. Faça a alteração.
3. Clique em "Commit changes...", escreva em uma linha o que mudou e confirme em "Propose changes".
4. Na tela seguinte, clique em "Create pull request".

O GitHub cria sozinho uma cópia do projeto na sua conta para guardar sua alteração. A gente revisa o pull request e, se precisar, conversa com você nos comentários.

## Quatro combinados: linguagem simples, teste, fonte e respeito

- **Escreva para quem está começando.** Use frases curtas e explique todo termo técnico na primeira vez que ele aparecer.
- **Teste antes de propor.** Se for um comando ou uma instrução para IA, rode ou teste antes de mandar.
- **Diga de onde veio.** Se usou um estudo, um artigo ou uma documentação, coloque o link.
- **Respeite todo mundo.** Pergunta básica é bem-vinda, e ninguém aqui é exposto por errar.

Ao contribuir, você concorda que sua contribuição fica sob a mesma licença dos guias, a [CC BY 4.0](LICENSE).

## Onde cada arquivo fica

Cada guia tem uma pasta própria dentro de `guias/`, e cada skill, dentro de `skills/`:

```
guias/
  nome-do-guia/
    README.md       o guia em si
    instrucao.txt   o texto pronto para colar na IA, quando houver
    pagina.html     a versão visual do guia, quando houver
skills/
  nome-da-skill/
    SKILL.md        as instruções que a IA segue
    README.md       como instalar, exemplos e ideias de melhoria
```
