# Specs da Rotina

Uma spec por funcionalidade nova ou por mudança de comportamento, escrita antes do código. Correção de texto ou bug pequeno não precisa.

- Modelo: [`regras/modelo-spec.md`](https://github.com/rizzygo/favos/blob/main/regras/modelo-spec.md) do repositório `favos`.
- Para escrever a seção Problema, a skill [`entender-o-problema`](https://github.com/rizzygo/favos/tree/main/plugins/favo-carreira/skills/entender-o-problema) ajuda a achar o problema por trás do pedido.
- Todo critério de aceite que dá para automatizar vira um passo em [`../testes/e2e.js`](../testes/e2e.js).
