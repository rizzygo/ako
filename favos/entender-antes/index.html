Entender antes

Rodar o que não se entende é o jeito mais rápido de quebrar algo e o mais lento de aprender. Com esta skill, a IA explica primeiro e deixa a decisão de rodar com você.

A skill entra sozinha quando você cola um comando, um arquivo de configuração ou uma mensagem de erro, ou pergunta "o que isso faz?".

A IA explica em quatro passos antes de você rodar

1

Identifica o que chegou

Comando, arquivo ou erro. Se faltar algo que muda a explicação, faz no máximo duas perguntas.

2

Explica parte por parte

Uma linha por pedaço, na ordem em que acontece, com palavras do dia a dia.

3

Diz o que acontece ao rodar

Se só lê ou altera, se dá para desfazer, o que pode dar errado e como conferir.

4

Confere o entendimento

Termina com uma pergunta curta para você responder com as suas palavras.

1

Instale

2 min

No Claude Code, instale o plugin favo-estudo. A skill passa a valer em todos os seus projetos e recebe as atualizações com claude plugin update favo-estudo@favos.

terminal
claude plugin marketplace add rizzygo/favos
claude plugin install favo-estudo@favos

Para desfazer, rode claude plugin uninstall favo-estudo@favos. Com o plugin, você chama a skill pelo nome com /favo-estudo:entender-antes.

Outra ferramenta, ou só esta skill

Para instalar só no projeto atual, rode na raiz do projeto. A pasta .claude/skills funciona no Claude Code, no GitHub Copilot e no Cortex Code.

terminal
mkdir -p .claude/skills/entender-antes
curl -fsSL https://raw.githubusercontent.com/rizzygo/favos/main/plugins/favo-estudo/skills/entender-antes/SKILL.md \
  -o .claude/skills/entender-antes/SKILL.md

Para desfazer, rode rm -r .claude/skills/entender-antes. Sua ferramenta não lê skills? Peça a ela: "leia o arquivo .claude/skills/entender-antes/SKILL.md e siga o procedimento".

2

Teste com um comando que você já viu por aí

2 min

Abra uma sessão nova e cole um comando, por exemplo:

O que isso faz? sudo apt update && sudo apt upgrade -y

sudo apt update && sudo apt upgrade -y

sudo roda como administrador.

apt update atualiza a lista de pacotes disponíveis. Não instala nada.

&& só roda a segunda parte se a primeira der certo.

apt upgrade instala as versões novas dos pacotes.

-y responde "sim" a tudo, sem perguntar.

Ao rodar

Só lê ou altera? Altera: troca pacotes do sistema pelas versões novas.

Dá para desfazer? Não com um comando só. Voltar exige instalar de novo a versão antiga de cada pacote, um por um.

Com o que você leu, qual parte você tiraria para revisar a lista antes de instalar?

Funcionou se a resposta explica cada parte antes de dizer o risco e termina com uma pergunta para você. O texto não precisa vir igual ao exemplo.

Como melhorar esta skill

A skill é um arquivo de texto curto, para todo mundo conseguir ler e melhorar. Leia o SKILL.md e abra uma issue ou um pull request no repositório favos.
