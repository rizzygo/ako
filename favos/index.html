Instale os plugins no Claude Code

2 min

No Claude Code, adicione o marketplace dos Favos e instale os plugins que fazem sentido para você.

terminal
claude plugin marketplace add rizzygo/favos
claude plugin install favo-estudo@favos
claude plugin install favo-trilhas@favos
claude plugin install favo-carreira@favos

Para desfazer, rode claude plugin uninstall com o nome do plugin, por exemplo claude plugin uninstall favo-estudo@favos.

Usa outra ferramenta? Cada aba traz o comando para baixar só aquela skill, e o README dos Favos mostra como copiar todas para a pasta que o seu agente lê.
