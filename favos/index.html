Favos

Cada favo é um plugin aberto para a sua IA de código, em português. As skills fazem a IA explicar antes de mudar, ensinar perguntando, sugerir o próximo passo nas trilhas do Ako e montar um plano de carreira.

Escolha uma skill nas abas acima ou nos cartões abaixo para ver o que ela faz, como instalar e como testar. Todas funcionam no Claude Code e em outras ferramentas que leem skills no formato SKILL.md.

Não usa IA de código? Comece pelo guia Dicas antes de rodar

O guia Dicas antes de rodar funciona no ChatGPT, no Claude, no Gemini e em qualquer IA que aceite instruções. Você cola um texto uma vez e a IA passa a dizer o que muda, como desfazer e como conferir.

Instale os plugins no Claude Code

2 min

No Claude Code, adicione o marketplace dos Favos e instale os plugins que fazem sentido para você.

terminal
claude plugin marketplace add rizzygo/favos
claude plugin install favo-estudo@favos
claude plugin install favo-trilhas@favos
claude plugin install favo-carreira@favos

Para desfazer, rode claude plugin uninstall com o nome do plugin, por exemplo claude plugin uninstall favo-estudo@favos.

Usa outra ferramenta? Cada aba traz o comando para baixar só aquela skill, e o README dos Favos mostra como copiar todas para a pasta que o seu agente lê.
