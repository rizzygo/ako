Estudar junto

Com esta skill, a IA ensina perguntando e você aprende explicando. A resposta pronta só vem quando você pede. Ako é uma palavra maori em que ensinar e aprender são a mesma coisa.

A skill entra sozinha quando você diz que está estudando, se preparando para uma prova ou entrevista, ou pede "me ensina" sobre um assunto de tecnologia.

A IA ensina em quatro passos, perguntando

1

Descobre o ponto de partida

Pergunta o que você já sabe e para que precisa do assunto.

2

Explica em partes pequenas

Uma ideia por vez, com um exemplo do dia a dia e uma pergunta depois de cada parte.

3

Pede a explicação de volta

Você explica com as suas palavras, e a IA diz o que ficou certo e o que faltou.

4

Termina com prática

Um exercício de até 30 minutos, uma pergunta para pensar e material gratuito.

Sem terminal, até pelo celular: cada tópico da trilha Primeiros passos e dos mapas das áreas tem o botão Copiar prompt, em "Estudar com IA". Ele junta este método com o conteúdo do tópico, e você cola no ChatGPT, no Claude, no Gemini ou na IA que usa.

1

Instale

2 min

No Claude Code, instale o plugin favo-estudo. A skill passa a valer em todos os seus projetos e recebe as atualizações com claude plugin update favo-estudo@favos.

terminal
claude plugin marketplace add rizzygo/favos
claude plugin install favo-estudo@favos

Para desfazer, rode claude plugin uninstall favo-estudo@favos. Com o plugin, você chama a skill pelo nome com /favo-estudo:estudar-junto.

Outra ferramenta, ou só esta skill

Para instalar só no projeto atual, rode na raiz do projeto. A pasta .claude/skills funciona no Claude Code, no GitHub Copilot e no Cortex Code.

terminal
mkdir -p .claude/skills/estudar-junto
curl -fsSL https://raw.githubusercontent.com/rizzygo/favos/main/plugins/favo-estudo/skills/estudar-junto/SKILL.md \
  -o .claude/skills/estudar-junto/SKILL.md

Para desfazer, rode rm -r .claude/skills/estudar-junto. Sua ferramenta não lê skills? Peça a ela: "leia o arquivo .claude/skills/estudar-junto/SKILL.md e siga o procedimento".

2

Teste com um assunto que você está estudando

2 min

Abra uma sessão nova e peça, por exemplo:

Me ensina o que é DNS.

antes de explicar, a IA pergunta

1. O que você já sabe sobre DNS? Pode ser pouco.

2. Para que você precisa: curiosidade, trabalho, prova ou entrevista?

Funcionou se a IA pergunta antes de explicar. Se você pedir a resposta direta, ela dá.

Como melhorar esta skill

A skill é um arquivo de texto curto, para todo mundo conseguir ler e melhorar. Leia o SKILL.md e abra uma issue ou um pull request no repositório favos.
